# Android VPN 恢复测试版

<!-- bfclash:changelog:begin -->
- 网络、地址或路由变化后重新建立 VPN 隧道，避免只更新 DNS 而留下失效连接。
- 增加 VPN 路径与本机代理的对照检测；连续两次仅 VPN 路径失败时尝试恢复，并设置冷却时间。
- 手动停止 VPN 后取消检测与待执行恢复，避免自动重新开启。
- 保持旧测试版包名 com.lansway.client.beta 和原签名，可从 0.2.26-beta.18 覆盖升级。
<!-- bfclash:changelog:end -->

包含 ARM64、ARMv7 和 x86_64 Android 安装包，不改变正式版更新渠道。

已通过签名、包名、版本与架构校验，以及原生服务和应用层单元测试。原故障的底层触发原因尚未完全确认，锁屏、网络切换和长期运行仍需真机验证；本测试版不代表已证明故障永不复发。
