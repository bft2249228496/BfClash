# Android 0.2.29-rc.3 测试候选

本次合并连接操作与规则保存修复，沿用 RC1/RC2 的更新暂停续传、息屏统计优化和一致快照备份。

## 本次变化

- 连接页增加手动刷新。读取失败时明确提示数据不可用或可能已过期，保留旧数据并提供重试；读取成功后提示消失。
- 单条及全部关闭会等待结果，处理中防止重复操作，失败时给出反馈；较早的读取结果不能覆盖关闭后的新状态。
- 连接与请求搜索支持目标端口、域名加端口、IP 加端口，忽略查询首尾空白。
- 修复四种通配符/重匹配规则保存或恢复时可能报错的问题。

## 沿用的行为

- 更新下载可暂停并返回；之后再次检查更新继续。仅在来源校验身份一致时拼接已有下载，无校验信息的来源安全重下。没有独立后台下载任务页。
- 备份使用运行中数据库的一致快照，避免遗漏 WAL 中已提交的修改。
- 锁屏停止通知秒级刷新，退到后台暂停界面统计轮询，VPN 继续运行。
- 健康锁屏时外网检测间隔五分钟，疑似故障一分钟，深度休眠跳过外网探测。健康锁屏时，隐性故障首次发现可能更慢。
- 本次未增加后台计时器、额外网络探测或新的省电策略。

## 安装与验收边界

保留正式版包名 com.bfclash.client 和原签名，手动安装会覆盖现有正式版或 RC；请先备份。不是隔离安装，不是正式发布，不自动推送或安装。

小米15用户已安装 RC1，但尚无电池统计或待机对照测量。不能声称实际省电幅度已验证。本版的真实设备连接刷新/关闭、更新暂停续传、备份恢复、锁屏及切换网络后的恢复仍待验收。

候选身份应为版本0.2.29-rc.3，ARM64 versionCode2061、ARMv7 1061、x64 4061；需以本次 CI 实际 APK、原签名和公开下载校验完成后才能交付，旧 RC2 构建不能替代。
