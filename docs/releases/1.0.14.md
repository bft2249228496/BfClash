# Tailscale 登录修复与备份恢复体验优化

- 修复嵌入式 Tailscale（`BfClash-Tailscale`）在旁路由 / Fake-IP DNS 环境下无法获取控制面公钥、导致登录超时的问题，控制面解析改用 `ProxyServerHostResolver`，`SystemDialer` 改用默认拨号器，并补充 `ExtraRootCAs`、设备名 `BfClash` 与核心日志转发。
- 修复 WebDAV 恢复与本地备份恢复后未自动触发配置重载的问题，恢复完成后自动热加载配置并刷新节点组。
- 修复「恢复所有数据」时会用备份里的默认值覆盖本地当前「恢复策略」的问题，并在「覆盖」模式下恢复前增加二次确认提示，避免误删本地配置与规则。

包含 Windows AMD64 安装包和应用内更新使用的 ZIP。

Android 包含 ARM64、ARMv7 和 x86_64，与 Windows 包来自同一源码提交。
