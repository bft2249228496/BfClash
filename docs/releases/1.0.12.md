# 测速地址 HTTPS 升级与 Windows 启动稳定性

自动把代理组和代理提供者使用的旧版 HTTP gstatic 测速地址改为 HTTPS。订阅刷新后仍然生效，并保留自定义测速地址和订阅下载地址。

Windows 版在首次启动 Core 前完成 TUN 授权，并等待 Core 初始化完成后再应用设置，避免启动阶段配置应用失败。

节点测速失败会以脱敏形式记录（不含节点凭据），并保留 Windows 安装器日志与更新交接阶段记录，方便排查。

包含 Windows AMD64 安装包和应用内更新使用的 ZIP。

源码提交 `b883115c218d1bb1e61f177cad5146000b20ca4c`。[构建记录](https://github.com/bft2249228496/BfClash/actions/runs/45539101415)

Android 包含 ARM64、ARMv7 和 x86_64，与 Windows 包来自同一源码提交；正式版包名 `com.bfclash.client`，可从 1.0.11 覆盖升级。
