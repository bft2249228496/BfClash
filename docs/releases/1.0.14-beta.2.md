# 修复 Tailscale 控制面登录超时及恢复后自动重载配置

- 修复嵌入式 Tailscale（`BfClash-Tailscale`）在旁路由 / Fake-IP DNS 环境下无法获取控制面公钥、导致登录超时（`context deadline exceeded`）的问题：控制面解析改用 `ProxyServerHostResolver`，`SystemDialer` 改用默认拨号器，并补充 `ExtraRootCAs`、`Hostname` 与 `tsnet` 日志输出。
- 修复 WebDAV 恢复与本地备份恢复后仅落盘数据库、未自动触发 Mihomo 内核重载的问题：恢复完成后自动调用配置重载并刷新节点组状态。

包含 Windows AMD64 安装包和应用内更新使用的 ZIP。

Android 包含 ARM64、ARMv7 和 x86_64，与 Windows 包来自同一源码提交。
