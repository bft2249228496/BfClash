# 单节点测速徽章

代理卡片上的延迟改为可点击的胶囊徽章：未测速显示「测速」，失败显示「重试」，测速中显示转圈。悬停时徽章高亮并提示仅测该节点；点徽章只重测当前节点，点卡片其余区域仍是选择节点。

延迟颜色按明暗主题各取一套，全部主题预设 × 明暗的对比度 ≥ 4.6（WCAG AA ≥ 4.5）；徽章底色与边框由文字色按透明度派生，不新增固定颜色。

包含 Windows AMD64 安装包和应用内更新使用的 ZIP。

Android 包含 ARM64、ARMv7 和 x86_64，与 Windows 包来自同一源码提交；正式版包名 `com.bfclash.client`，可从 1.0.11 覆盖升级。
