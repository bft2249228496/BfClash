# Android 0.2.29-beta.3

- 恢复预览版 PRE 角标：Beta/RC 构建使用预览显示环境，正式版本仍使用正式环境。
- 修复内核未响应或连接数据格式异常时被误显示为“暂无连接”；读取失败保留已有列表并显示重试提示。合法空列表仍正常显示。
- 保留 Beta2 的更新包名过滤、安装前包名及递增版本号校验、安装权限提示和失败反馈，避免 Beta 错装独立 RC 包后循环更新。

此包沿用原 BfClash Beta 的 com.lansway.client.beta 包名及签名，会覆盖原 Beta，先备份、无需卸载。正式版/独立 RC 应用不能用此包覆盖更新。小米15使用 ARM64 包。旧 Beta1 若仍提示 RC3，请直接下载此包手动覆盖一次；Beta2 可使用应用内检查更新。

省电策略不变。没有手机耗电幅度或完整 VPN 网络恢复的实测结论；构建和测试通过不等于设备验收。窗口/连接刷新等仍须实际使用反馈。更新继续入口仍是再次检查更新，没有独立后台下载任务页。
