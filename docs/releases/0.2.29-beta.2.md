# Android 0.2.29-beta.2 — Beta update-loop repair

This candidate updates the existing **BfClash Beta** application (`com.lansway.client.beta`). It does not replace the separate `com.bfclash.client` stable/RC app. Do not uninstall the existing Beta app to upgrade; back up its configuration before manually installing the matching package.

The old Beta updater incorrectly offered RC packages with another application ID. Installing them can leave the original Beta unchanged and repeat the update prompt. This build filters releases by installed package identity and rejects APKs with another package ID or a non-increasing version code before opening the installer. Missing install permission is reported separately; opening the installer is not treated as completed installation. Failed installer launch no longer redirects to an unrelated stable package.

**One-time recovery:** download this Beta repair package directly. The old updater may continue selecting RC3 until the matching repair is installed. Do not keep using that repeating prompt. Original package/signature continuity and higher per-ABI version codes must be verified before publication.

Includes prior download pause/resume, connection feedback/IPv6 and consistent-backup fixes. The screen-off power strategy is unchanged; no Xiaomi15 savings or real-device update completion is claimed.
