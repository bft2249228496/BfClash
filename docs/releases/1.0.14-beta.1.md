# 修复 Tailscale 控制面登录超时

修复嵌入式 Tailscale（`BfClash-Tailscale`）在旁路由 / Fake-IP DNS 环境下无法获取控制面公钥、导致登录超时（`context deadline exceeded`）的问题：

- 控制面域名解析改为使用 `ProxyServerHostResolver`（走代理 DNS），避免读取系统 DNS 返回的 Fake-IP 地址。
- `SystemDialer` 改为使用默认拨号器，使控制面与 DERP 建连走 Clash 出站路径，与上游 mihomo 保持一致。
- 补充 `ExtraRootCAs`（`ca.GetCertPool()`）、设备名 `Hostname: "BfClash"`，并将 `tsnet` 日志转发至核心日志便于排查。

包含 Windows AMD64 安装包和应用内更新使用的 ZIP。

Android 包含 ARM64、ARMv7 和 x86_64，与 Windows 包来自同一源码提交。
